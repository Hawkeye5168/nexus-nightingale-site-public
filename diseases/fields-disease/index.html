Correction · 14 November 2026

Fields disease — corrected entry

This URL previously conflated two different conditions.

CorrectionNot a dossier release

What changed: the previous page at this URL was titled “Fields disease (FNIP1 deficiency)” and described FNIP1 biology. That was a conflation. The page has been withdrawn and replaced with this correction.

01The correction

Fields disease is a separate, extremely rare neuromuscular condition reported in two sisters, with no established gene in the record used for this project. It is not FNIP1 deficiency.

FNIP1 deficiency is an autosomal recessive inborn error of immunity — immunodeficiency 93 with hypertrophic cardiomyopathy (OMIM 619705) — caused by biallelic loss of FNIP1. Its corrected dossier is at FNIP1 deficiency →.

We are not presenting a Fields disease dossier. A disease with no established gene cannot be given a gene-targeted route merely because an unrelated report used the same label.

02What remains true

The FNIP1 dossier has been corrected and rebuilt. The previous FIELDS-001 bundle is retained only as a retracted internal record and is not a public release.

The correction follows TJ Compassion: do only good; no lies; no fake; always be honest. A wrong disease identity is not a wording defect — it changes the entire document.

03Status

Fields disease entry: withdrawn. FNIP1 deficiency: corrected public summary at /diseases/fnip1-deficiency/. Independent review: outstanding.
